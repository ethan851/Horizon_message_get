## [用 Git 的 --author 标志对抗 AI 机器人垃圾信息](https://archestra.ai/blog/only-responsible-ai) ⭐️ 8.0/10

Archestra 的一篇博客文章介绍了如何使用 Git 的 --author 标志过滤 GitHub 仓库中来自 AI 机器人的垃圾提交和拉取请求。这种技术允许维护者通过检查提交作者字段来屏蔽已知机器人账户的贡献。 AI 生成的垃圾信息对开源项目来说是一个日益严重的问题，低质量或恶意的贡献会让维护者不堪重负。这种简单、低技术含量的解决方案提供了一种即时防御，无需依赖 GitHub 的政策或复杂的自动化。 这种方法利用了 Git 现有的 --author 标志，根据作者姓名或邮箱模式过滤提交，可在 CI/CD 或预接收钩子中用于拒绝垃圾信息。然而，它仅在机器人使用一致且可识别的作者信息时有效，并可能意外屏蔽具有相似名称的合法用户。

hackernews · ildari · May 18, 15:24 · [社区讨论](https://news.ycombinator.com/item?id=48181125)

**背景**: Git 为每次提交记录了提交作者和提交者，可通过 --author 标志查看。AI 机器人越来越多地被用来在 GitHub 上生成垃圾拉取请求，通常使用虚假或通用的作者名称。--author 标志允许维护者以编程方式在合并之前拒绝来自可疑作者的提交。

陪审团驳回了埃隆·马斯克对 OpenAI 和山姆·奥特曼的诉讼，裁定其索赔提出过晚。该判决于 2026 年 5 月 18 日作出，标志着马斯克在挑战 OpenAI 转为营利性机构的诉讼中遭遇法律挫败。 该裁决为 OpenAI 潜在的 IPO 和未来融资扫清了重大法律障碍。它也凸显了诉讼时效在备受瞩目的公司纠纷中的重要性，尤其是涉及非营利起源的案件。 陪审团认定马斯克等待太久才提出索赔，因为 2019 年和 2021 年的微软交易与诉讼核心的 2023 年交易相似。陪审团仅回答是/否问题，因此确切理由尚不明确。

**背景**: ALPR 系统使用摄像头和人工智能捕获车牌号码和位置数据。执法部门和私人实体广泛部署了这些系统，形成了庞大的车辆行驶数据库。隐私倡导者警告说，这些数据可以在没有搜查令的情况下用于跟踪个人，尤其是在跨多个辖区汇总时。

## [CS 专业毕业生失业率升至 7.0%，顶尖大学入学人数骤降](https://wallstreetcn.com/member/articles/3772222) ⭐️ 8.0/10

纽约联储报告显示，2026 年第一季度 22 至 27 岁计算机科学专业毕业生失业率达到 7.0%，远高于护理（2.1%）和特殊教育（0.7%）。与此同时，普林斯顿和加州大学伯克利分校的 CS 专业入学人数分别下降了 51%和 59%。 这一数据表明曾经繁荣的科技就业市场可能正在降温，这将影响学生的职业选择以及大学对相关项目的投入。顶尖学府 CS 入学人数的下降也反映出对该领域就业前景的普遍担忧。 数据来自纽约联储的季度劳动力市场分析。此外，金融和法律等传统高薪行业也在削减入门级岗位，摩根大通的实习录取率从 2.8%降至 0.7%，普华永道计划将入门级招聘削减三分之一。

**背景**: 计算机科学一直是美国最受欢迎的学位之一，拥有高起薪和强劲的就业率。然而，近期大型科技公司的裁员以及潜在的毕业生过剩可能是失业率上升的原因。尽管整体经济并未衰退，当前数据显示了显著的转变。
