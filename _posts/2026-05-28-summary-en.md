## [Huawei Unveils 'Tau Law' for Semiconductor Scaling via Time Domain](https://t.me/zaihuapd/41597) ⭐️ 9.0/10

At the 2026 IEEE International Symposium on Circuits and Systems (ISCAS) in Shanghai, Huawei announced the 'Tau (τ) Law', proposing 'time scaling' as a replacement for traditional geometric scaling in semiconductor advancement. The company has already designed and mass-produced 381 chips based on this principle over the past six years, and will launch a new Kirin mobile chip using logic folding technology this autumn. The Tau Law offers a new path to continue performance scaling as Moore's Law approaches physical limits, shifting focus from shrinking transistor dimensions to reducing time constants across devices, circuits, and systems. This could redefine the semiconductor industry's roadmap, especially for Chinese firms facing advanced process restrictions. The Tau Law is formally described in a paper titled 'A Time Scaling Theory for Multi-Layer Electronic Systems' by Huawei's semiconductor head He Tingbo. Huawei expects that by 2031, high-end chips based on this law will achieve transistor density equivalent to that of a 1.4nm process, and future development will emphasize open cooperation.

telegram · zaihuapd · May 27, 09:00

**Background**: Traditional semiconductor scaling follows Moore's Law, which predicts that transistor count doubles every two years mainly by shrinking feature sizes (geometric scaling). As physical limits approach, alternative approaches like 'more than Moore' and system-level optimization gain attention. The Tau Law introduces 'time scaling', which reduces propagation delays and switching times through techniques like logic folding, potentially delivering performance gains without requiring extreme lithography.

## [Go moves to support generic interface methods](https://github.com/golang/go/issues/77273) ⭐️ 8.0/10

The Go team has accepted a proposal (issue #77273) to support generic methods in interfaces, a long-requested feature that will allow interfaces to have type parameters in their method signatures. This change will significantly enhance Go's expressiveness by enabling type-safe generic interfaces without relying on type assertions or workarounds, addressing a key limitation since generics were introduced in Go 1.18. The proposal is still in the design phase with no implementation yet, but it has strong community traction (199 points, 147 comments). The feature will allow interfaces to declare methods with their own type parameters, similar to generic functions.

hackernews · f311a · May 27, 09:02 · [Discussion](https://news.ycombinator.com/item?id=48291575)

**Background**: Go generics, introduced in Go 1.18, allowed generic functions and types but not generic methods on interfaces. This forced developers to use empty interfaces or specific concrete types for methods that needed to operate on different types. The new feature would enable writing truly generic interfaces, improving code reuse and type safety.

## [Critical 7-Zip Heap Overflow Vulnerability Disclosed, Fixed in 26.01](https://socprime.com/blog/cve-2026-48095-7-zip-heap-overflow-flaw/) ⭐️ 8.0/10

A high-severity heap buffer overflow vulnerability (CVE-2026-48095) in 7-Zip's NTFS archive handler has been disclosed, allowing arbitrary code execution via crafted archives. The vulnerability was fixed in version 26.01, released on April 27, 2026. 7-Zip is one of the most widely used file archivers globally, and this vulnerability could lead to remote code execution with no user action beyond opening a malicious archive. Its disclosure highlights the critical need for prompt patching to prevent large-scale exploitation in phishing and social engineering campaigns. The flaw is a heap buffer write overflow in the NTFS handler, exploitable via crafted archives with .7z, .zip, or .rar extensions due to 7-Zip's fallback logic that routes files to the NTFS parser when other handlers fail. The vulnerability has been assigned CVE-2026-48095 and was reported by GitHub Security Lab.

telegram · zaihuapd · May 27, 08:01

**Background**: A heap overflow occurs when a program writes more data to a buffer allocated on the heap than it can hold, potentially corrupting adjacent memory. This type of vulnerability can be exploited to overwrite function pointers or other critical data structures, often leading to arbitrary code execution. 7-Zip is an open-source file archiver with a long history and broad adoption, making vulnerabilities in it particularly impactful.
