## [OpenAI 发布 GPT-6 Astra，宣称基准测试全面领先](https://t.me/zaihuapd/43634) ⭐️ 10.0/10

OpenAI 发布了 GPT-6 Astra，称其为迄今最智能、对齐程度最高的模型。该公司报告其在 FrontierMath Tier 4、ARC-AGI-3 和 ExploitBench 上均取得最高分，并公布了新的 API 定价。 作为 OpenAI 的旗舰模型，GPT-6 Astra 可能会重新定义前沿 AI 在推理、安全与智能体任务上的能力标准。此次发布也表明 API 定价与性能方面的竞争压力正在影响整个大模型生态。 标准 API 定价为每百万输入 token 10 美元、每百万输出 token 50 美元，缓存读取和写入另行收费。官方还给出 FrontierMath Tier 4 得分 98%、ARC-AGI-3 得分 99.9%、ExploitBench 得分 100%，并将素数间隔上界推进到 186；API 提供快速模式，处理速度最高可达标准模式的 2.5 倍。

## [Asahi Linux 正式支持 Apple M3 芯片](https://asahilinux.org/2026/09/m2-episode-1/) ⭐️ 8.0/10

Asahi Linux 宣布正式支持 Apple M3 芯片，持续推进其在 Apple Silicon 上运行 Linux 的使命。这一里程碑标志着 M3 版 Mac 现可作为该项目的内核与驱动程序所支持的硬件平台。 此举使 Linux 成为最新 Mac 硬件上的现实选择，为用户提供更多操作系统选项，并增强了开源生态。它也表明逆向工程苹果专有芯片的工作正在稳步推进，最终可能推动 Linux 在 Mac 上得到更广泛采用。 根据社区反馈，M3 的早期支持仍缺少稳定的睡眠和 HDMI 功能，这些被视为影响采用的障碍。与其他 Apple Silicon 支持一样，GPU 加速依赖项目自有的 OpenGL 驱动而非苹果的 Metal，导致部分工作负载性能受影响。

hackernews · mdp2021 · Sep 6, 14:08 · [社区讨论](https://news.ycombinator.com/item?id=49586698)

**背景**: Asahi Linux 是一个开源项目，通过逆向工程技术将 Linux 移植到 Apple Silicon Mac 上，这些芯片没有公开的官方文档。项目由 Hector Martin 发起，支持包括 M1 到 M4 系列在内的多款苹果芯片。由于苹果不正式支持其硬件运行其他操作系统，Asahi Linux 的所有硬件适配都需要独立开发，并向上游 Linux 内核提交代码。
