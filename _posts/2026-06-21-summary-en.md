## [China develops fiber optic micro-tweezer 100,000x stronger than traditional optical tweezers](https://www.stdaily.com/web/gdxw/2026-06/19/content_534836.html) ⭐️ 9.0/10

Researchers from Anhui University and the University of Science and Technology of China have fabricated a novel three-dimensional fiber optic micro-tweezer on a commercial fiber tip using femtosecond laser hybrid manufacturing, published in Nature. The device integrates optical transmission, photothermal conversion, material response, and microstructural mechanical output into a single fiber, achieving continuous force control with output forces over 100,000 times stronger than traditional optical tweezers. This breakthrough enables precise, low-damage, programmable three-dimensional manipulation of microscale objects, particularly single cells, with unprecedented force, overcoming the limitations of traditional optical tweezers (weak force, inability to manipulate opaque objects) and mechanical microgrippers (limited precision in confined spaces). It offers a new technological pathway for life sciences research and minimally invasive microsurgery. The micro-tweezer operates by adjusting input light power to precisely control force output, and it can perform accurate sampling within spaces as small as hundreds of micrometers. The device combines optical and mechanical effects—using photothermal conversion to induce material deformation, acting like a 'miniature dexterous hand' at the cellular scale.

telegram · zaihuapd · Jun 20, 15:19

**Background**: Traditional optical tweezers use strongly focused laser beams to trap and manipulate microscopic objects via radiation pressure, but they provide weak forces (typically picoNewtons) and cannot handle opaque objects. In contrast, this new micro-tweezer uses femtosecond laser hybrid manufacturing to build a 3D microstructure on an optical fiber tip that converts light energy into mechanical force via photothermal effects, delivering forces in the microNewton range. Photothermal conversion is the process where absorbed light is converted into heat, driving thermal expansion or phase change in the material to produce motion.

## [HTTP QUERY Method Proposed for Safe Queries with Body](https://httpwg.org/http-extensions/draft-ietf-httpbis-safe-method-w-body.html) ⭐️ 8.0/10

The IETF HTTP Working Group has proposed a new HTTP QUERY method that allows query parameters to be sent in the request body while retaining the safe and idempotent properties of GET. This addresses the URI length limitation problem and enables reliable caching, retries, and automatic recovery for query operations, which is particularly useful for complex API queries. The draft defines a new Accept-Query response header for servers to declare supported query formats, and the method is similar to POST but safe and idempotent; the current version expires in December 2026.

telegram · zaihuapd · Jun 20, 06:28

**Background**: HTTP GET is safe and idempotent but has limited URI length, while POST allows a request body but is not safe or idempotent, causing issues with caching and retries. The proposed QUERY method combines the benefits of both, allowing large query parameters in the body while preserving safe and idempotent semantics.

LM Studio collaborated with Apple at WWDC to run the 1-trillion-parameter Kimi K2.6 model on a cluster of four Mac Studio machines using a preview version of LM Studio, with secure remote access demonstrated via LM Link from a MacBook and iPhone. This achievement shows that consumer-grade hardware can handle state-of-the-art large language models through distributed inference, potentially democratizing access to powerful AI for developers and researchers without expensive data center infrastructure. The Kimi K2.6 model uses a Mixture-of-Experts (MoE) architecture with 1 trillion total parameters but only 32 billion active parameters per token. The demonstration also highlighted LM Link, a feature providing end-to-end encrypted remote access to local models.

telegram · zaihuapd · Jun 20, 07:02

**Background**: Large language models typically require powerful GPUs and large memory, making them hard to run on individual devices. Distributed inference splits the model across multiple machines to pool resources. LM Studio is a desktop app for running local LLMs, and LM Link is its remote access feature announced in early 2026. MoE is an architecture where only a subset of parameters are activated per input, enabling larger total model sizes with manageable computation.
