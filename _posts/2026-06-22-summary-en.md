## [Prefer Duplication over Wrong Abstraction](https://sandimetz.com/blog/2016/1/20/the-wrong-abstraction) ⭐️ 8.0/10

Sandi Metz's 2016 blog post argues that developers should prefer code duplication over creating incorrect abstractions, which are harder to fix later. This principle challenges the dogmatic application of DRY (Don't Repeat Yourself) and provides practical guidance for balancing abstraction and duplication in software design. The post emphasizes that removing duplication from a wrong abstraction is often more costly than leaving duplication in place, and suggests waiting until the correct abstraction is clear.

hackernews · rafaepta · Jun 21, 16:08 · [Discussion](https://news.ycombinator.com/item?id=48620090)

**Background**: In software engineering, abstraction is a technique to reduce complexity by hiding details. The DRY principle encourages avoiding duplication, but sometimes leads to premature or incorrect abstractions that are difficult to maintain. Sandi Metz is a well-known software developer and author.

**Discussion**: Commenters generally agree with the article, sharing personal experiences with over-engineered code. Some note that duplication is acceptable unless it violates 'single source of truth'. Others mention that functional programming reduces abstraction issues.

## [Norvig's Lisp Interpreter in Python Tutorial](https://norvig.com/lispy.html) ⭐️ 8.0/10

Peter Norvig's classic 2010 tutorial 'How to Write a (Lisp) Interpreter (In Python)' remains a highly recommended resource for learning to build programming languages. This tutorial demystifies how interpreters work and has inspired countless developers to explore language implementation, bridging theory and practice. The tutorial uses Python to implement a Scheme-like Lisp interpreter in under 100 lines of code, with a second part adding more features like macros.

hackernews · tosh · Jun 21, 15:36 · [Discussion](https://news.ycombinator.com/item?id=48619831)

**Background**: Lisp is a family of programming languages known for its fully parenthesized syntax and homoiconicity, making it ideal for teaching interpreters. An interpreter is a program that directly executes code without prior compilation. This tutorial by Peter Norvig, a renowned computer scientist, is widely regarded as the best starting point for beginners wanting to understand language implementation.

**Discussion**: The community response is very positive, with users praising it as the best resource to get started with writing a programming language. Comments also reference previous discussions and related projects like Ribbit, a compact R4RS Lisp implementation.

## [Polymarket Paid Creators for Fake Trading Videos](https://www.wsj.com/business/media/polymarket-social-media-bets-prediction-market-441cdeb5) ⭐️ 8.0/10

The Wall Street Journal revealed that Polymarket hired dozens of young creators to produce fake trading videos on simulated websites, with undisclosed paid sponsorships, violating US advertising laws. This deceptive practice undermines trust in prediction markets and could lead to regulatory action against Polymarket, affecting its user base and the broader crypto industry. Out of 1,105 analyzed videos, 70% showed $1.9 million in fake bets, and 118 videos claimed nearly $900,000 in wins that would have actually lost over $166,000.
