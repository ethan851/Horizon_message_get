## [Kimi K3: Open-Source 2.8T Model Tops Frontend Code Arena](https://t.me/zaihuapd/42637) ⭐️ 9.0/10

Moonshot AI released Kimi K3, the world's first open-source 2.8 trillion parameter model, which achieved a score of 1679 to rank first in the Frontend Code Arena, surpassing previous leaders including Fable 5. This release marks a significant milestone in open-source AI, demonstrating that a Chinese lab can produce a frontier-level model with novel attention architecture and top coding performance, potentially accelerating AI accessibility and innovation worldwide. Kimi K3 is built on Kimi Delta Attention (KDA) and Attention Residuals (AttnRes) architectures, supports a 128K to 1M token context window, and includes native visual capabilities. It achieved first place in 6 out of 7 evaluation domains in the Frontend Code Arena.

telegram · zaihuapd · Jul 18, 02:29

**Background**: Large language models (LLMs) rely on attention mechanisms to process sequences. Traditional full attention has quadratic complexity, while linear attention reduces it. Kimi Delta Attention is a hybrid linear attention module that extends Gated DeltaNet with finer-grained gating. Attention Residuals replace standard residual connections with learned, input-dependent attention over layer outputs. Open-source models like this allow broader access and community contributions, challenging proprietary models.

## [LG Monitors Silently Install Software via Windows Update Without Consent](https://videocardz.com/newz/lg-monitors-silently-install-software-through-windows-update-without-user-consent) ⭐️ 8.0/10

LG monitors have been found to automatically install software through Windows Update without user consent when connected via HDMI. The issue affects all LG monitor users and bypasses typical consent mechanisms. This is a serious security and privacy concern because the software gains full system access and internet connectivity, is installed silently with no user interaction, and executes at every boot. It represents a supply-chain trust issue affecting potentially millions of users. The software is treated as a driver package by Windows Update, allowing it to install with system privileges. Affected users can disable automatic installation of manufacturer apps via Group Policy or Device Installation Settings.

hackernews · baranul · Jul 18, 10:21 · [Discussion](https://news.ycombinator.com/item?id=48956688)

**Background**: Windows Update can automatically deliver driver packages signed by hardware vendors, which Windows treats as trusted updates. In this case, LG is distributing software that is not a driver but a full application through this mechanism, which users cannot easily prevent. This exploits Windows' automatic driver update feature to silently install potentially unnecessary or unwanted software.

## [TSMC Announces A14 Process to Begin Production in 2028](https://t.me/zaihuapd/42643) ⭐️ 8.0/10

TSMC announced its next-generation A14 process technology, slated for production in 2028. Compared to the N2 process, A14 offers up to 15% faster speed at same power or 30% lower power at same speed, along with over 20% higher logic density. This announcement underscores TSMC's continued leadership in semiconductor manufacturing, setting the roadmap for future high-performance chips used in AI, HPC, and mobile devices. The new process will enable more powerful and efficient processors, driving innovation across the tech industry. TSMC also plans to introduce the A16 process in late 2026, which will serve as an intermediate node. The A14 process will utilize second-generation GAA nanosheet transistors and a new standard-cell architecture to achieve its performance and density gains.

telegram · zaihuapd · Jul 18, 05:00

**Background**: Semiconductor process nodes refer to the manufacturing technology used to create integrated circuits, with smaller nodes typically offering better performance and efficiency. TSMC's N2 (2nm-class) process is expected to enter mass production later this year, while A14 (1.4nm-class) represents a further advancement. The shift to GAA (Gate-All-Around) transistors in the A14 marks a significant architectural change from FinFET transistors used in previous nodes.
