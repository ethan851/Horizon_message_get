## [GitHub 堆叠 PR 进入公开预览](https://github.blog/changelog/2026-07-30-stacked-pull-requests-are-now-in-public-preview/) ⭐️ 8.0/10

2026 年 7 月 30 日，GitHub 宣布堆叠拉取请求（Stacked Pull Requests）进入公开预览，并将在未来几天内向所有仓库逐步推出。未来几周内，合并队列（merge queue）对堆叠 PR 的支持也将渐进上线。 这是 GitHub 多年来最大的工作流变更之一，允许开发者将大型改动拆分为一串更小、相互依赖的 PR，并独立地进行审查和合并。这可能让更多开发者接触堆叠工作流，从而提升整个生态的代码审查质量和迭代速度。 堆叠（stack）将 PR 按顺序排列成链，每个 PR 代表一个改动的聚焦层次，并支持一键合并整个堆叠。开发者可以通过 GitHub 界面、gh stack CLI 或 GitHub API 管理堆叠，合并队列集成也在逐步加入。

hackernews · tomzorz · Jul 30, 16:26 · [社区讨论](https://news.ycombinator.com/item?id=49112232)

**背景**: 堆叠拉取请求是一种工作流：多个 PR 一个叠一个地构建，每个 PR 的目标分支是它下方 PR 的分支，而不是直接指向主分支。这样可以将大型功能拆分为更小、可独立审查的单元，从而减少合并冲突并加快审查速度。此前 GitHub 仅通过第三方工具支持此类工作流，此次发布使其成为平台内置的一等公民功能。官方 gh-stack 工具和文档将其描述为“把大型改动拆成小型的、可审查的拉取请求”。

## [物理学家解开μ子谜团，旧结果不再吻合](https://www.quantamagazine.org/physicists-solve-a-muon-mystery-now-old-results-dont-add-up-20260729/) ⭐️ 8.0/10

物理学家解决了长期存在的μ子 g-2 反常问题，即μ子磁矩在理论与实验之间的偏差。然而，这一解决却使先前已被接受的测量与理论结果变得不一致，强烈暗示了标准模型之外存在新物理的可能性。 这一突破对几十年来一直极为成功的粒子物理标准模型构成了挑战。如果这种不一致经得起检验，它可能指向尚未发现的粒子或力，从根本上重塑我们在最小尺度上对宇宙的理解。 费米实验室的 muon g-2 实验以 0.14 ppm 的精度测量了μ子的反常磁偶极矩，这是在布鲁克海文国家实验室早期工作基础上的延续。该反常最早出现在上世纪 90 年代末至本世纪初，当时布鲁克海文的测量结果首次与μ子反常 aμ=(g-2)/2 的理论预测出现偏差。

hackernews · ibobev · Jul 30, 15:22 · [社区讨论](https://news.ycombinator.com/item?id=49111305)

**背景**: μ子是电子的更重同类粒子，其磁矩可以用粒子物理标准模型以极高精度计算。g-2 反常，即测得的(g-2)/2 与理论计算不一致，二十多年来一直是标准模型之外新物理最诱人的线索之一。解开这个谜团需要要么修正理论计算，要么改进实验测量，要么提出全新的物理解释。
